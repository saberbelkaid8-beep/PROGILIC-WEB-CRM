# Algerian administrative divisions

`algeria-locations.json` contains the 69 wilayas and 1,541 communes in force
after Law 26-06. The data was compiled from the Journal officiel by
[djazairdev/wilayas](https://github.com/djazairdev/wilayas) at commit
`0b3b6ab2ac1b1569469285d8fe5e7df18666fcdf`, using its `data/wilayas.csv` and
`data/communes.csv`.

The upstream dataset is released under CC0 1.0. This CRM retains the previous
Arabic spellings where possible for compatibility with existing client records.
